# Provenance: doc-pdf

Written from scratch for this kit (2026-10-08). MIT. No third-party skill text or code was used.

- **Source:** the public documentation of the open library it drives — `pypdf` (BSD-3-Clause); optional external tools: pandoc and LibreOffice (run as separate programs, not bundled).
- **Bundled code:** none. The skill tells the assistant to write small snippets at run time; the library is installed only with the person's consent, into a personal venv at `~/.ai-sdlc/venv`, outside the repo.
- **Licence:** MIT, as the rest of the kit.
